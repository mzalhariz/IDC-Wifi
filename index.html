Auto-Detect Setup
Use MacroDroid (free) or Tasker to create a home screen shortcut that reads your WiFi and opens this app automatically. One tap = instant detection!
MacroDroid (Recommended - Free)
1 Install MacroDroid from Play Store
2 Create new Macro → Trigger: Shortcut Launched
3 Action: Open Website / HTTP GET
4 Enter this URL (tap to copy):
https://mzalhariz.github.io/IDC-Wifi/?ssid={wifi_ssid}
5 In MacroDroid, use variable {wifi_ssid} — it auto-fills your connected WiFi name
6 Save macro → Add MacroDroid shortcut to home screen
Result: Tap shortcut on home screen → MacroDroid reads your WiFi → opens this page → hall detected instantly!
Tasker Alternative
1 Task → Action: Browse URL
2 URL:
https://mzalhariz.github.io/IDC-Wifi/?ssid=%WIFII
3 %WIFII is Tasker's variable for connected WiFi SSID
